# 美股牛市逃顶仪表盘

基于多因子交叉验证的美股牛市末期风险监测系统。它不是预测单日最高点，而是观察估值、市场内部结构、流动性、信用、盈利和市场领导者是否同时恶化。

在线版本：[us-bull-exit-dashboard.richleotao.chatgpt.site](https://us-bull-exit-dashboard.richleotao.chatgpt.site)

## 模型结构

- 9个风险维度、27项核心指标
- 100分制综合风险指数
- 市场结构、信用/流动性、盈利趋势三项确认机制
- 点击维度筛选指标
- 响应式桌面和移动端界面

## 已接入数据

`app/api/fred/route.ts` 从FRED读取宏观和信用数据。目前接入：

- 10年期实际利率
- 美国金融条件指数
- 美元广义指数20日变化
- 高收益债信用利差
- 投资级债信用利差
- 10年—2年收益率曲线
- 首次申领失业救济人数

接口按指标独立加载；单个序列暂时不可用时，不会阻塞其他数据。

## 本地运行

要求 Node.js 22.13 或更高版本。

```bash
npm run install:ci
npm run dev
```

生产构建：

```bash
npm run build
```

## 重要说明

仪表盘中带有“FRED＋日期”标识的项目来自自动数据源；其余项目仍可能是模型示范值。风险分数和阈值需要通过历史周期回测进一步校准。本项目不构成投资建议。
